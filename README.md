# 🍕 Pizza Sales Data Analysis Dashboard

## 📌 Project Overview
An end-to-end Pizza Sales Data Analysis project developed using **MySQL and Power BI** to analyze sales performance, customer ordering patterns, revenue trends, and pizza-level performance.

The project includes SQL-based data analysis and an interactive 2-page Power BI dashboard.

## 🛠️ Tools & Technologies
- MySQL
- SQL
- Power BI
- DAX
- Data Visualization

## 📊 Dataset
The dataset contains pizza orders, order details, pizza information, pricing, categories, sizes, and ingredients.

### Dataset Tables
- `orders`
- `order_details`
- `pizzas`
- `pizza_types`

## 🔍 SQL Analysis
SQL was used for:
- Data validation and quality checks
- Total revenue calculation
- Total orders and pizzas sold
- Average Order Value
- Revenue by pizza category
- Revenue by pizza size
- Top 10 pizzas by revenue
- Monthly revenue trends
- Orders by hour
- Weekday vs Weekend order analysis

## 📈 Power BI Dashboard

### Page 1 — Executive Overview
The executive overview provides:
- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value
- Monthly Revenue Trend
- Revenue by Pizza Category
- Revenue by Pizza Size
- Top 10 Pizzas by Revenue
- Orders by Hour
- Weekday vs Weekend Orders

### Page 2 — Pizza Performance Analysis
The second page focuses on detailed product performance:
- Top 10 Pizzas by Revenue
- Revenue by Pizza Category
- Revenue by Pizza Size
- Pizza-level sales details
- Pizzas Sold
- Revenue comparison
